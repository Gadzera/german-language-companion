# German Language Companion

Eine interaktive Web-App zum Deutschlernen mit Quizzen und Übungen — von A1 bis B1 und darüber hinaus.

## Technologien

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Lokale Entwicklung

```sh
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
npm install
npm run dev
```
